# Lanark Mountain Access Map

Interactive road and trail map for Lanark Parcel 21, Bear Lake County, Idaho.

## Publishing
Upload `index.html` to the repository root. In GitHub Settings > Pages, choose **Deploy from a branch**, **main**, **/(root)**, and save. The public URL will be https://chadbstewart-code.github.io/lanark-mountain-access/ after deployment succeeds.

## Important limitations
The parcel boundary is provisional. Road/trail colors represent mapped road categories, not verified difficulty, legal access or seasonal passability. Owner-confirmed approaches include Mill Farm Road, Paris Ice Cave and German Dugway; these classifications must be distinguished from unverified routes.
